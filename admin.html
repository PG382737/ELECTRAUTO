Configuration du poste

1
Installer le driver ACR122U

Téléchargez le MSI Installer depuis le site ACS. Une seule fois par ordinateur.

2
Télécharger NFC Reader

Le pont entre le lecteur USB et le navigateur. Placez-le dans un dossier permanent.

3
Brancher le lecteur USB

Connectez le ACR122U. Windows le détectera automatiquement.

4
Lancer NFC Reader

Double-cliquez sur le .exe. La pastille de statut passera au vert.

Driver ACR122U NFC-Reader
Démarrage automatique avec Windows
  1. Appuyez sur Win + R
  2. Tapez shell:startup puis Entrée
  3. Copiez NFC-Reader.exe dans ce dossier
  4. Le serveur se lancera automatiquement au prochain démarrage
