Management Panel

Complete Guide

Your shop, simplified. Centralize employee management, vehicle tracking, real-time work order monitoring, media management and billing from any browser.

Secure Access

The panel is protected by a password and two-factor authentication (2FA). Upon login, a 6-digit code is sent by email. You can check the "Don't ask again for 30 days" option to simplify frequent logins.

After multiple failed attempts, access is temporarily locked to protect your account.

Overview

The management panel contains 5 main sections:

Employees

Manage your team and their NFC badges

Vehicles

Complete directory of all vehicles

Monitoring

Real-time work order tracking

Media

Photos and documents linked to vehicles

Dashboard

Full-screen NFC scanner for the workstation

Notifications

Real-time alerts with complete history

1 Employees

Adding an Employee

Click "New Employee" and fill in:

  • First name and last name
  • Hire date
  • NFC badge (optional, can be assigned later)

Employee List

The list displays all your employees with their hire date and NFC badge status. Each employee has 4 quick actions:

  • Statistics: View employee performance
  • Billed Hours: Manage monthly billed hours
  • Edit: Modify employee information
  • Delete: Remove the employee from the system

Employee Statistics

By clicking on an employee's name or the statistics icon, you access a detailed dashboard:

Period Filters: Today, This Week, This Month, This Year, All, or a specific month via the selector.

Statistics Cards:

  • Hours Worked: Total punched hours for the period
  • Billed Hours: Total hours billed to customers
  • Efficiency: Billed hours / worked hours ratio
    Green: 80% and above • Orange: 50-79% • Red: below 50%
  • Vehicles: Number of vehicles worked on
  • Average Time / Vehicle: Average duration per vehicle

Recent History: Paginated table showing each work order with date, vehicle, and duration.

Billed Hours

The clock icon opens the billed hours manager. This is where you enter the hours billed to customers.

  1. Select the month (defaults to the previous month)
  2. Enter the number of billed hours
  3. Add an optional note (e.g., "1 week vacation", "overtime")
  4. Click Add

You can edit or delete any entry at any time.

NFC Badges

Each employee can have an NFC badge assigned. This badge is used to "punch" work orders via the scanner.

  1. Edit the employee or create a new one
  2. Click Scan
  3. Hold the NFC badge in front of the reader
  4. The badge is automatically associated

2 Vehicles

Adding a Vehicle

Click "New Vehicle" and fill in:

  • Owner (required) and contact info (phone, email)
  • Reference: internal file number
  • Make (required), model, year, color
  • License plate and VIN
  • Vehicle photo: for quick identification
  • NFC badge: assign directly to the vehicle (optional)

Vehicle List

The list displays all vehicles with a search bar for quick filtering. Each vehicle shows:

  • Make, model, and year
  • Owner name and license plate
  • Status (active, paused, or inactive)
  • Number of assigned media
  • Actions: Detail, Edit, Delete

Vehicle Detail Page

By clicking on a vehicle name, you open its complete profile:

  • Photo and information: all vehicle data
  • Active work order: real-time timer, assigned employee, status
  • Statistics: total repairs, total time, number of employees
  • Work history: paginated table of all past work orders
  • Media: linked photos with shareable link
  • Notes: add, view, and delete internal notes

3 Monitoring

Monitoring is the real-time control center for your shop. A pulsing green dot confirms that data refreshes automatically every 5 seconds.

Active Work Orders

Each active work order displays:

  • Real-time timer: elapsed time updated every second
  • Vehicle: make, model, and plate
  • Employee: assigned employee's name
  • Status: Active (amber strip) or Paused (green strip)
  • Actions: Pause/Resume, Stop

Automatic Pause

The system automatically manages pauses according to the configured schedule:

  • Automatic pause at noon (lunch break)
  • Automatic resume at 1 PM
  • Automatic pause at 5 PM (end of day)
  • Automatic resume the next morning

Automatic actions are identified by the (sys) suffix in notifications.

Recent Activity

An activity feed shows the latest completed work orders with their total duration.

4 Media

Unclassified Photos

New photos appear in the "New" section. A badge indicates the number of unclassified media.

Classifying Photos

  1. Click "Classify" to activate classification mode
  2. Select the photos to classify
  3. Search for the vehicle in the search field (instant filtering)
  4. Click "Assign" to link the photos to the vehicle

Classified Photos

Classified photos are grouped by vehicle. The vehicle name is clickable and leads directly to its detail page.

Deleting and Sharing

Activate deletion mode with the trash icon to select and delete photos. Each photo can be shared via a direct link by clicking the copy icon.

5 Dashboard (NFC Scanner)

The Dashboard is designed to be permanently displayed on a workstation in the shop.

Full-Screen Scanner

Click "Open Scanner" to enter full-screen mode:

  1. The screen waits for an NFC scan
  2. An employee holds their badge in front of the reader
  3. The system identifies the employee and displays their name
  4. The employee scans a vehicle's badge
  5. The work order is automatically created or closed

Already have an active work order? The scan automatically closes it.
No active work order? The scan creates a new one.

NFC Reader Setup

The Dashboard shows the NFC reader connection status (green = connected, red = disconnected). Installation instructions are included in the interface: ACR122U driver, NFC Reader application, USB connection. Automatic startup with Windows option available.

Notifications

A bell in the top right displays a badge with the number of new notifications:

  • Work order started: a new work order has been opened
  • Work order completed: a work order has been finished
  • Work order paused: a work order has been paused
  • Work order resumed: a work order has resumed after a pause

In Configuration, you can enable/disable each type individually. The complete history is accessible via Configuration > Notification History.
